# HR--ANALYTICS-DASHBOARDS

## Project Overview
This HR Analytics Dashboard was built using Microsoft Power BI to analyze employee attrition and workforce trends for data-driven HR decisions.

## Key Insights
- **Total Employees**: 1,470
- **Total Attrition**: 237 employees
- **Attrition Rate**: 16%
- **Average Age**: 37 years
- **Average Salary**: 7K

## Dashboard Features
- **Attrition by Education Field** - Pie chart
- **Attrition by Job Role** - Bar chart  
- **Attrition by Age Group** - Bar chart
- **Attrition by Years at Company** - Line chart
- **Attrition by Salary Hike** - Bar chart
- **Attrition by Job Satisfaction** - Table

## Tools Used
- Microsoft Power BI Desktop
- Data Visualization
- Data Analysis

## How to Use
1. Download the `.pbix` file
2. Open with Power BI Desktop
3. Explore filters and visuals
